# Integrated Health Associates LLC — website

Single-page static site, deployed on Netlify as project `spontaneous-bublanina-477880`.

```
site/
├── index.html              ← the whole page (CSS + JS inline; portraits embedded as base64)
├── assets/
│   ├── logo-lockup.png     ← header logo
│   ├── logo-mark.png       ← footer mark
│   ├── favicon.png
│   ├── hero-poster.jpg     ← generated by scripts/generate-ihc-site-assets.sh (optional)
│   └── hero-loop.mp4       ← generated by scripts/generate-ihc-site-assets.sh (optional)
└── README.md
```

## Motion layer

The page is progressively enhanced. Everything renders without JavaScript; with it, you get:

- hero: animated aurora background, word-by-word headline, Ken Burns portrait, floating founder card, pulsing CTA
- hero video slot: `assets/hero-loop.mp4` fades in behind the hero **only if the file exists and can play**; otherwise the aurora shows
- ECG band: one-time draw, then a looping sweep and travelling dot while the band is on screen
- expertise ticker, count-up stats, staggered card reveals, 3D tilt on service and advisor cards, cursor spotlight on the dark team section
- sticky nav that compacts on scroll, scroll progress bar, mobile hamburger menu
- `prefers-reduced-motion` turns all of it off and shows the static layout

## Generate the hero media (Arcads)

```bash
./scripts/setup.sh                          # once: puts your Arcads key in .env
./scripts/generate-ihc-site-assets.sh       # poster still (Nano Banana 2) + 15s loop (Kling 3.0)
```

The script prints a credit estimate and asks before generating. Output lands in `site/assets/`.

## Deploy

Drag the `site/` folder onto the Netlify deploys page for the project, or:

```bash
npx netlify-cli deploy --prod --dir=site
```
